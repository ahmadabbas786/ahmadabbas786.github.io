# Ahmad Palsaniya — Resume Portfolio

A responsive, static portfolio website built from the supplied resume.

## Files
- `index.html` — complete website
- `Ahmad-Palsaniya-Resume.pdf` — downloadable resume

## Free GitHub Pages deployment
1. Create/login to GitHub.
2. Create a new **public** repository named `YOUR-USERNAME.github.io`.
3. Upload `index.html` and `Ahmad-Palsaniya-Resume.pdf`.
4. Open repository **Settings → Pages**.
5. Under Source, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. After deployment, open `https://YOUR-USERNAME.github.io`.

No custom domain is required.
